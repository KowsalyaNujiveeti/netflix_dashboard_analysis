# Netflix User Engagement & Churn Analysis

An Excel-based dashboard analyzing Netflix user behavior, engagement, subscription patterns, preferences, and churn.

## Project Overview

This project focuses on understanding user engagement and identifying patterns related to customer churn using Netflix user data.

## Analysis Includes

* User demographics and age groups
* Subscription types and premium subscribers
* User preferences by favorite genre
* Average watch time
* Watch sessions and engagement
* Churned users
* Churn by subscription type
* Country-wise user and subscription analysis
* Ratings and user preferences

## Tools Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Excel formulas
* Data cleaning and analysis

## Dataset

The dataset contains user-level information including demographics, subscription details, viewing behavior, engagement metrics, preferences, and churn status.

## Dashboard

The final Excel dashboard presents the key findings through interactive charts and supporting analysis.
